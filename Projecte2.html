About

This project is my own take on the horror genre. I modeled and textured all the assets in Blender, and implemented them in Unity 3D using the terrain editor. I also created custom particle systems to generate the fog, and designed a teleportation system to simulate an infinite forest.

Project Info

  • Role: Programmer, Designer, Modeler 3D, Texturizer
  • Team size: 1
  • Time frame: 3 weeks
  • Engine: Unity 3D

Introduction to the project

This game was created as a solo experiment to explore horror mechanics in a minimalist environment. The aim was to generate suspense and unease without relying on jumpscares.

Modeling and texturing

All assets were created from scratch in Blender and hand-textured to match the dark, atmospheric style of the game. The modeling process focused on simplicity and stylized details to enhance clarity in low-light settings.

Custom particle system and teleports

I designed a fog system using Unity's particle tools to create a layered, dense atmosphere. The teleportation mechanic allows players to walk through portals that reset their position in the forest, giving the illusion of endless space.

What I learned

This project helped me gain hands-on experience in Unity 3D, 3D modeling with Blender, and using particle systems creatively. I also improved my understanding of game flow, environment design, and solo development pacing.
