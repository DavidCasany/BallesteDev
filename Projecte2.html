About

Custom website designed and built from scratch to present information about the current state of the space industry. All layout, styling, and interactions were manually coded without templates, focusing on clarity, responsiveness, and clean design.

Project Info

  • Role: Programmer, Designer
  • Team size: 1
  • Time frame: 2 weeks
  • Languages: HTML, CSS, JavaScript

Introduction to the project

This project was a university assignment focused on building a fully custom website to showcase a personal interest. I chose to explore the topic of space exploration, designing a site that presents key aspects of the modern space race.

The website covers the origins of this renewed interest in space, highlights the main players in the industry, and explains NASA's plan to return to the Moon. Additionally, it includes a gallery of today’s most important rockets and a section with curated news and videos related to space exploration.

Structure & Semantics (HTML)

The website is divided into consistent and reusable parts: a header, which includes navigation links, a theme switcher, and a language toggle, and a footer, which remains the same across all pages. Each individual page has its own unique structure and content, tailored to its topic. HTML semantic elements were used to ensure the content is meaningful and accessible.

CStyling & Layout (CSS)

The layout was built using Flexbox and CSS Grid, allowing for an organized and clean presentation of images and information across different sections. The color scheme follows a simple and elegant combination of white, black, and grey, and uses a basic, readable font to ensure clarity. The website is also fully responsive, adapting to small screens and mobile devices for a smooth browsing experience.

Interactivity (JavaScript)

JavaScript was used to implement a theme switcher (light/dark mode) and a language selector, offering a personalized user experience. Additionally, clickable thumbnails in the news and video sections redirect users to external sources. On the main page, hovering over a video clip reveals a semi-transparent overlay with a short description of the video content, enhancing interactivity.

What I learned

Through this project, I strengthened my practical understanding of HTML, CSS, and JavaScript. I learned how to build a fully functional and responsive website from scratch, implement dynamic UI features, and design a structured and accessible user interface. It also taught me how to manage a multi-page layout efficiently, and how to balance design simplicity with interactivity.
